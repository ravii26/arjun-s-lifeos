# Project Memory

## Core
LifeOS personal productivity app. Dark/light themes via data-theme on html.
Inter font 400/500 only. Never 600/700. No red except delete confirmations.
Custom CSS vars (--surface-1, --primary, etc) — NOT shadcn tokens.
Inline SVG icons only, 20px, stroke 1.5. No icon libraries.
Card style: 14px radius, 0.5px border, no shadows. Spacing: 4/8/12/16/20/24/32/48/64px.
